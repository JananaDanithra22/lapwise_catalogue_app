# LapWise Catalogue App

## Project Description
LapWise is a laptop catalogue mobile app focused on the Sri Lankan market. It helps users browse and compare laptops available in Sri Lanka without providing a direct purchasing option. The app features a powerful comparison tool where users can select laptops and receive AI-powered suggestions based on Gemini 1.5.

Key features include:
- Real-time search with smart suggestions  
- Detailed laptop specifications, including seller details relevant to each laptop  
- Save comparisons and favorite laptops  
- Advanced search filters  
- AI suggestions to guide users in making wise purchasing decisions

### Problem Solved
When looking to buy a laptop in Sri Lanka, users often search through multiple websites to compare prices and specs manually or copy-paste details into external AI tools. LapWise consolidates all this information in one app, simplifying research and comparison to help users choose laptops more efficiently and confidently.

## Setup and Installation

1. Clone the repository:

git clone [https://github.com/JananaDanithra22/lapwise\_catalogue\_app.git](https://github.com/JananaDanithra22/lapwise_catalogue_app.git)

2. Navigate to the project directory:


cd lapwise\_catalogue\_app


3. Get Flutter dependencies:

flutter pub get


4. Configure Firebase for your own environment (set up Firebase Auth, Firestore, and Storage).  
5. Add your Gemini 1.5 API key in the relevant config files.  
6. Run the app on a connected device or emulator:


flutter run


------

## Usage
- Use the search bar for real-time laptop suggestions.  
- Browse laptops with detailed specifications and seller information based on the selected laptop.  
- Add laptops to your favorites or comparison list.  
- Receive AI-generated recommendations based on your selected laptops.  
- Apply filters like price range, brand, and processor to narrow down options.
